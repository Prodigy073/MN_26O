# ¿Qué son los métodos numéricos?
>Los métodos numéricos son herramientas muy poderosas para la solución de problemas. Son capaces de manipular sistemas de ecuaciones grandes, manejar no linealidades y resolver geometrías complicadas, comunes en la práctica de la ingeniería y, a menudo, imposibles de resolver en forma analítica. (Chapra, 2015).

Por lo tanto, la utilización de estos métodos permiten al usuario aventajarse y armarse para enfrentar situaciones en las que puede parecer imposible resolver un problema, encontrar un resultado o calcular una operación que, de hacerlo de forma manual o tradicional, se volvería muy tediosa. En general, aumentan la capacidad de un ingeniero para resolver problemas.
